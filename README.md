# Neon Dash — Playable Slice

Kısa neon cyber side-scroller. HD sahne + animasyonlu runner.

## Oyna

https://mirkul34.github.io/neon-dash/

## Kontroller

| Tuş | Aksiyon |
|-----|---------|
| A / D | Hareket |
| Space / W | Zıpla (bırak = kısa zıplama) |
| S / ↓ | Eğilerek yürü (alçak geçit) |
| Shift / J | Dash (i-frame + trail) |
| R | Koşuyu yeniden başlat |
| Esc | Pause / title |
| M | Sessiz |
| Enter | Başla / tekrar |

## Hedef

**8/8 orb** topla, sonra EXIT portalına gir. Rank: süre + orb + ölüm.
