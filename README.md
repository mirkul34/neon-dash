# NEON DASH — 02:17 (5 dk dilim)

Mobil öncelikli playable slice. Hikâye bozulmadan: lobi → ıslak koridor (kepenk) → bulaşık (lazer) → sahte EXIT → çamaşır presi (hayalet plaka) → damga.

## Oyna
https://mirkul34.github.io/neon-dash/

## Kontroller
- **Mobil:** ekran tuşları (◀ ▶ JUMP DASH S E) · ☰ pause
- **Masaüstü:** A/D hareket · Space zıpla · S eğil · Shift dash · E kapı/EXIT · Esc menü · R oda reset · M mute

## Yol
1. Lobi → SERVİS kapısı (E)
2. Kepenk altından geç (S)
3. Lazerler — dash yetmez, eğil
4. Sahte EXIT denenebilir (hikâye twisti) veya SERVİS kapısıyla devam
5. Öl → hayalet 6 sn tekrar oynar · iki plakayı sen+hayalet bas
6. Anı ◆ + DAMGA → dilim biter
